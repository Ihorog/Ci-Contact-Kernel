# Ci-Contact-Kernel

Minimal first implementation layer of the Ci Contact Kernel / Universal Control Core.

## Run

```bash
npm install
npm start
```

Open:

- `http://localhost:3000/ci/widget`
- `http://localhost:3000/ci/status`

## API

- `POST /ci/signal`
- `POST /ci/command`
- `POST /ciopen/webhook`
- `GET /ci/status`
- `GET /ci/memory`
