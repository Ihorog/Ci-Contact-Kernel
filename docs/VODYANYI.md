# Водяний — `HOME.WATER.VODYANYI`

`Водяний` — зареєстроване виконавче поле однієї позиції: запас, замовлення й доставка питної води. Це не окремий персонаж. NFC, крапля на екрані, кнопка, голос і розмовний запит є рівноправними входами до однієї координати та не містять власної бізнес-логіки.

## Контракт сигналу

- `1 клік` / NFC / явна фраза «Водяний, замов воду» → `execute_standard`.
- `2 кліки` / «змінити умови» → `change_conditions`; стандартне замовлення не відправляється.
- згадка води без явної виконавчої дії → координата розпізнається, але замовлення не створюється.
- «воду привезли» / `confirm_delivery` → користувацьке підтвердження фактичної доставки.

Один клік є явною авторизацією незмінної стандартної процедури. Він прибирає повторний діалог, але не вимикає машинні інваріанти: захист тригера, незмінність перевіреного профілю, свіжа ціна, ліміт вартості, доступність, ідемпотентність, відсутність активного дубля та доказ відповіді реальної служби.

## Стан

`REGISTERED → AUTHORIZED → QUOTED → SUBMITTED/CONFIRMED/IN_TRANSIT → DELIVERED`

`DELIVERED` встановлюється лише після явного підтвердження користувача. Підтверджена доставка додається до обліку руху повних бутлів. Якщо вихідний залишок невідомий, стан позначається як оцінка від підтвердженої доставки, а не як точний ручний перерахунок.

Поки активна доставка не підтверджена, крапля лишається видимою та пульсує. Коротке натискання показує лише:

- ціну;
- кількість і літраж;
- час доставки;
- стан.

## API

- `GET /ci/vodyanyi/status` — координата, готовність, облік і мінімальний підсумок.
- `POST /ci/vodyanyi/signal` — єдина точка входу для всіх каналів.

Приклад стандартного сигналу:

```json
{
  "coordinate": "HOME.WATER.VODYANYI",
  "marker": "drop",
  "clicks": 1,
  "action": "execute_standard",
  "source": "ui.drop",
  "signalId": "client-generated-uuid"
}
```

Заголовок `x-ci-vodyanyi-token` обов'язковий для виконання та підтвердження доставки. Секрет не записується в NFC-мітку, URL, GitHub або журнал операції.

## Виконавчий адаптер

`VODYANYI_EXECUTOR_URL` приймає два послідовні запити з однаковим ключем ідемпотентності:

1. `action=quote` — повертає `quoteId`, `available=true`, `currency=UAH`, `totalUAH`, `verifiedAt`, `deliverySlot`.
2. `action=submit` — лише після локальної перевірки котирування; повертає `accepted=true`, `orderId`, `status`, `confirmationRef`, `evidence`.

Без підключеного адаптера код чесно повертає `NOT_READY` і не симулює замовлення.

Стан координати у Cloudflare зберігається в одному Durable Object `VODYANYI_STATE`. Він послідовно обробляє сигнали та не дозволяє двом одночасним NFC/UI запитам обійти блокування дубля.
